# Portfolio de Zabrinna Vargas Antinori

Portfolio profesional de Zabrinna Vargas Antinori: estrategia y comunicación digital, marketing de contenidos y SEO, creatividad y coordinación de proyectos.

Web: <https://zabrinnavargas.github.io/>

## Tecnología

Sitio estático multipágina hecho con [Astro](https://astro.build/). Los filtros de proyectos funcionan solo con HTML y CSS; la ficha flotante de los casos usa [GSAP](https://gsap.com/). Los casos se escriben en Markdown con un esquema validado.

## Desarrollo

Requiere Node.js 22.12 o posterior y pnpm.

```bash
pnpm install
pnpm dev      # servidor local
pnpm check    # revisión de tipos y plantillas
pnpm build    # compila el sitio en dist/
pnpm verify   # valida páginas, enlaces y navegación
```

La web se publica en GitHub Pages automáticamente al actualizar `main`.
